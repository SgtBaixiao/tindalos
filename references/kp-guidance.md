# 守秘人任务把控指南（Keeper Guidance）

> 来源：《克苏鲁的呼唤》第七版守秘人规则书 · 第一章「介绍」（§1.1 游戏概览 / §1.2 合作与竞争 / §1.3 游戏范例）与第五章「游戏系统」（§5.1 何时掷骰）。
> 用途：Tindalos 生成剧本时对**任务推进、场景控制、检定节奏**的把控依据。
> 原文提取见 `references/sources/rulebook-1-120.txt`。

## 1. 守秘人的角色：电影导演

> 「守秘人会选择一个故事来运行游戏……这里守秘人的角色有一点点像电影导演，只是演员们不知道剧情会怎么发展。」

- 守秘人设计场景，向玩家描述**周围环境、人物和遭遇的事件**；玩家宣告行动；守秘人交代**后果**。
- 游戏的主体是**语言的交互**——剧本的每一幕、每一场都必须以"可描述、可回应、有后果"的方式产出。
- 守秘人应**公正地运行游戏**，让调查员的对手"狡猾而卑鄙"——反派有动机、有策略、不降智。

## 2. 何时引入检定（冲突才掷骰）

> 「若不掷骰……那么也就没有紧张感或戏剧性了。」「没必要为任何事情掷骰……每个人都能做好的普通日常事务就应当这样无需掷骰。」

- **戏剧性时刻才检定**：场景事件中的冲突/险境/对抗才需要 `conditions`（检定条件）。
- **普通日常直接叙述**：赶路、打听、翻阅等平凡行动直接写成推进性描述，不打断节奏。
- **目标明确**：检定应绑定一个清晰目标（如"悄悄撬锁"而非"撬锁"），成败后果才可预期。

### 难度分级（用于事件 conditions 设计）

| 难度 | 判定 | 用法 |
|---|---|---|
| 常规 | ≤ 技能值 | 绝大多数情形 |
| 困难 | ≤ 技能值/2 | 专业人士也棘手的任务，偶尔使用 |
| 极难 | ≤ 技能值/5 | 触及人类可能性边界，极端情形 |

- 对抗性检定：对手技能 ≥50 → 困难；≥90 → 极难。
- 简单任务**免去检定**——把检定留给有挑战性的情景。

## 3. 叙事与节奏

- **合作叙事**：没有通常意义的赢家和输家；参与者一起达成目标（发现并阻止阴谋）。
- **失败有代价但可继续**：调查员可能受伤、精神崩溃甚至死亡，但故事继续推进——剧本不应因一次失败而"卡死"。
- **调查员的对手**通常是"异常存在或不利情境"，由公正的编排者（KP/Tindalos）安排，而非纯粹的恶意。
- **范例交互节奏**（规则书 §1.3）：
  - KP 抛场景：「好了伙计们，你们有什么计划吗？」
  - 玩家合议行动 → KP 叙述环境反应 → 冲突时引入检定 → 交代后果。

## 4. 对 Tindalos 生成的具体要求

1. **每幕必须有明确任务推进**：简报 → 行动 → 新线索/新危机 → 下一幕入口。
2. **场景事件三事件制**（entry → trigger → outcome）对应"进入描述 → 冲突/发现 → 后果"，其中 trigger 是**戏剧性时刻**，应带 `conditions`（检定）。
3. **不因失败断线**：outcome 应同时给出成功路径与失败路径的后果（如"检定成功发现线索；失败则错过，但下一场景仍可补救"）。
4. **对手设计**：反派有动机、有伪装/策略、避免无脑正面冲突（参考模组中缪楚"不惜一切代价避免战斗"）。
