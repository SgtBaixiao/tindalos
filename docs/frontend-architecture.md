# 前端模块与维护约定

本说明供维护者修改页面、图编辑器和请求流程时查阅，回答代码放在哪里、模块之间如何依赖，以及修改后怎样验证。

## 模块各自承担什么

页面外壳负责导航、主题入口、错误展示和按需加载。图编辑器只在打开工作台后加载，资料、问答与记忆页面各自加载所需代码和样式。共享模块提供稳定的小接口，输入草稿由实际使用它的表单保存。

| 位置 | 职责 | 可依赖的本地模块 |
|---|---|---|
| `src/ui` | 图标、页标题、主题、日期和共享卡片样式 | 同目录模块 |
| `src/lib` | 请求、领域类型、图映射、布局和进度解析 | 同目录模块 |
| `src/store` | 采用中的剧本修订、节点和编辑历史 | 状态层与基础库 |
| `src/features` | 准备表单、场次记录和目录读取 | 功能模块、基础库与共享界面 |
| `src/components` | 图节点、详情编辑器和任务订阅 | 图组件、基础库、状态层与共享界面 |
| `src/site` | 页面组合、导航和路由适配 | 按实际页面组合上述模块 |

下图描述运行时的依赖方向。类型引用也遵守目录约束，运行时循环另行检查。

```mermaid
flowchart TD
  shell[页面外壳] --> pages[按需加载的页面]
  pages --> forms[功能表单]
  pages --> graph[图编辑器]
  forms --> lib[请求与领域基础库]
  graph --> store[剧本状态]
  store --> lib
  forms --> ui[共享界面]
  graph --> ui
```

## 输入与采用状态分别管理

备团正文、场次摘要和确认事实是本地输入草稿。它们保存在各自表单中，输入文字不更新采用中的剧本，也不刷新模组或剧本目录。工作台只处理提交、打开修订和任务终态，目录在挂载和任务结束时刷新。

图状态保存完整采用修订。批量节点变更先按 ID 分组，再遍历节点；未改变的节点保留对象引用，重复测量和不存在节点的删除不会通知订阅者。详情编辑器只订阅选中节点的身份、类型和内容，因此拖动位置不会重新渲染表单。

节点尺寸测量必须写回图状态。画布在测量完成或节点结构变化时适配视野，内容编辑和拖动保持现有视野。图组件开启可见元素渲染；它仍需持有全部节点，不能据此推断大图帧率或内存上限。

## 样式与交互约定

颜色、字体和焦点状态由共享主题定义；页面样式随路由加载。跨页面复用的卡片样式由使用页面显式导入，不借用其他页面的加载顺序。修改样式时直接修改所属规则，避免把新规则追加到文件末尾反复覆盖。

表单保留可访问名称和键盘焦点，手机输入字号至少为 16px。关闭的资料抽屉隐藏其交互控件，上传文件可从键盘进入。日期按浏览器本地时区显示，底层时间戳保持原值。主题保存到本地存储，并同步同源窗口的存储变化；减少动态效果的系统偏好由全局样式处理。

## 检查如何运行

在前端目录运行以下命令。格式检查、模块检查、测试和构建体积检查已加入 CI；本轮只在本机执行，尚无远端 CI 结果。

```bash
npm run format:check
npm run check:modules
npm test
npm run build
npm run check:bundle
```

模块检查使用 TypeScript 语法树读取静态导入与导出，检查依赖方向、运行时循环和首屏对图代码的误引入。构建检查递归统计入口静态依赖，确认工作台仍为按需加载入口，并计算 gzip 体积。动态模块内部的循环、样式循环、浏览器交互和渲染耗时需要另外验证。

| 首屏预算 | 上限 |
|---|---:|
| JavaScript 原始体积 | 230000 字节 |
| JavaScript gzip 体积 | 75000 字节 |
| CSS 原始体积 | 16000 字节 |
| CSS gzip 体积 | 5000 字节 |

以上上限是执行者为防止本轮优化退化设置的工程预算，尚非用户确定的产品性能目标。不要为通过检查随意扩大上限；需要变更时先测量实际加载行为，并在[决策日志](refactor-decision-log.md)记录依据。

当前证据和复测方法见[界面验收](ui-refactor-validation.md)。
