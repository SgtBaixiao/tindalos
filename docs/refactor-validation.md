## 性能结果保持方法边界

| 指标 | 原基线 | 重构后 | 测量范围 |
|---|---:|---:|---|
| 模拟生成 p50 | 138.087ms | 初测 98.398ms，复测 114.785ms | 同机 12 次，每种模型替身调用固定延迟 20ms |
| 模拟生成 p95 | 180.606ms | 初测 157.299ms，复测 153.678ms | 生成图和本机开销，包含并行调度波动 |
| 幕、NPC 规划调用数 | 各 2 次 | 各 1 次 | 固定输入、同一个确定性生成器 |
| 5000 节点、200 项位置变更 p50 | 7.2445ms | 0.192375ms | Node.js 中批量变更算法，30 次样本 |
| 生成期间 HTTP 读取 p50/p95 | 未测 | 12.363ms / 24.143ms | 20 个客户端、400 次读取，12 项生成任务 |

模拟生成基线从原始提交归档运行，输入为固定港口调查文本，检查点与存储显式使用内存资源。重构后减少重复规划调用；事件边由 12 条恢复为生成器的 8 条，输出语义也有变化，不能将速度差全部归因于调度优化。样本数量小，p95 对单次波动敏感，复测结果一并保留。

前端对照复制原算法，使用相同节点与位置变更，独立测纯状态操作。算法复杂度由每项变更遍历全图改为按 ID 聚合后一次遍历；截图和单元测试验证保存功能，尚未测浏览器拖动帧率、布局时间和内存峰值。

HTTP 使用真实 Uvicorn/FastAPI 回环连接，20 个客户端各读取 20 次，交替访问剧本列表与任务状态。12 项任务先等待 500ms 模拟外部延迟，再执行真实离线生成图。读取 400 次无错误，最大延迟 32.369ms。该测试持续时间短、数据量小，没有公网和真实模型负载。

## 后续验收需要原始主持证据

本轮没有调用付费或真实模型，没有取得用户完整模组、实际玩家行动和 KP 裁定，也没有独立 KP 主持验收。线索字段和 NPC 上下文已能编辑及保存，尚未实现带页码的自动事实抽取和条件调查图。失败后的替代路径仍是可编辑内容，系统不会执行调查可达性分析，也不会根据游玩行动自动更新角色知识。

正式内容验收应固定模组文件哈希和页码、采用修订、模型与提示词配置，由未参与开发的 KP 标注关键事实、证词真伪、取得条件和状态变化。使用漏检、绕路、角色死亡、个人知情与确认状态改变等反例逐项复核。语义判断校准后，再决定引入事实裁判、自动提取和更多修复操作，避免沿用数量指标作产品结论。

自动恢复远端调用、公开账号权限、多主机运行、长时压测、大规模中文检索和断电恢复也未验收。它们分别需要明确场景与独立证据；本轮决策未将这些列为已经实现的能力。
