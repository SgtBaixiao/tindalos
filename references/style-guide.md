# Tindalos 风格与设计规范（运行时注入版）

> 以下规范浓缩自《克苏鲁的呼唤》第七版守秘人规则书（第一/二/五章）与官方模组
> 《留地不留头》《吴老爷娶亲》《燃烧的星辰》。生成剧本时必须遵循；
> 详见 references/ 下三份详细文档（kp-guidance / lovecraftian-style / scenario-design）。

## 任务把控（KP 守则）

- 守秘人如电影导演：描述环境/人物/事件 → 玩家行动 → 交代后果；剧本的每个场景都须"可描述、可回应、有后果"。
- 冲突与戏剧性时刻才引入检定（conditions）；普通日常直接叙述，不打断节奏。
- 对手"狡猾而卑鄙"：有动机、有策略、有伪装，不降智、不无脑正面冲突。
- 检定难度：常规 ≤技能值 / 困难 ≤技能值一半 / 极难 ≤技能值五分之一；简单任务免检定。
- 失败不卡死：每条线索可有替代获取途径，事件 outcome 同时给出成功与失败路径的后果。

## 叙事节奏

- 六段骨架：背景铺垫 → 任务简报（明确目标）→ 调查探索（信息递进）→ 情报揭示 → 转折危机（颠覆对前文的解读）→ 高潮对峙 → 尾声余波。
- 时间表推进：每幕至少推进一个事件 + 一个新 NPC + 一条线索/危机；灾难性事件后留「后遗症阶段」供角色消化与重新集结。
- 每阶段必须产出新信息；转折改变玩家对前文的看法。
- 氛围母题贯穿全剧：选定 1–2 个环境/物象母题（如暴雨、蛇、旧印），每幕至少出现一次变奏。

## 语言风格（洛氏宇宙恐怖）

- 三主题：科学幻想（真相可考据）、哥特式恐怖（旧宅/地窖/修道院/暴雨夜）、虚无主义宇宙恐怖（宇宙对人漠不关心）。
- 核心观念：人类规律在宇宙中毫无效用；真相不可名状、接触即疯狂；神话元素保持"不可知性"（神秘、非人、不自我解说）。
- 描写手法：感官压制（潮湿/黑暗/气味/声音叠加）；细节写实（尺寸、材质、痕迹、年代、口音）；暗示与留白代替直白怪诞；少用"极其恐怖"类形容词，用具体物象（沸腾的圣水、发黑的石墙、缝眼獠牙）替代。
- 恐怖曲线：前期克制铺垫（写实调查），后期集中爆发（恐怖异象）；铺垫与爆发的落差即恐怖。
- 民俗恐怖变体：传统仪式（嫁娶/节庆/祭祀）可承载恐怖——仪式越庄重，渗透其中的异常越痂人；身份欺骗可藏在体面礼俗之下（如神话生物伪装成贵族遗脉）。
- 理智损失量化：san 0/1（成功无损失/失败损失1）、1/1d8（成功损失1/失败1d8）等格式；涉及理智损失时给出**具体的症状表现与行为后果**（幻觉、遗忘、执念、人格碎片），而非笼统「疯了」。

## 剧情设计

- 场景三事件制：entry（进入与环境描写）→ trigger（冲突/发现，戏剧性时刻，带 conditions）→ outcome（后果与出路）。
- 线索链：线索互相呼应——数量矛盾、隐藏物证、碎片拼合、跨场景符号呼应、反常自然现象；调查期埋设的细节在转折/高潮期回收。
- NPC：双层身份/伪装、动机约束（行为模式由动机推导）、细节质感（年龄/口音/出身/体征）、功能分工（向导/线索源/情报源/威胁）。
- 检定格式：「一个成功的{技能}检定可以{发现/得知/确定}{具体信息}」；同一地点可多级检定逐步揭示。
