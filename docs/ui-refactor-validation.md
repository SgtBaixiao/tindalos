# 界面重构与性能验收

本记录说明 2026-11-19 的界面、组件性能和模块规范重构结果，供维护者核对实际变化与验证范围。本轮延续原始提交上的本地修改，未提交、推送或发布。

## 界面围绕备团档案组织

首页和工作台采用暖纸、深绿色墨、铜色标记、衬线标题与细分隔线。首页的调查图由 SVG 绘制，字体使用系统字体，没有新增图片或字体下载。桌面常驻侧栏，手机切换为横向栏目导航。

工作台把准备依据、采用中的剧本、实际场次与评测入口分别组织。节点卡片和编辑抽屉使用同一主题，取消节点悬停位移与强阴影。模组、问答、历史、评测和记忆页面共用页标题及表单规范，关闭的资料抽屉不会留下键盘可访问的隐藏控件。

首页直接显示内容，旧的强制启动动画及其两个时序测试已删除。原先测试依赖固定等待时间，现改为等待真实路由完成按需加载，保留导航、错误、问答和数据展示验收。

## 首屏资源已经减少

两组数据均以文件字节数和 gzip level 9 为口径，比较首页入口及其静态依赖。十进制 kB 按 1000 字节换算。

| 入口资源 | 重构前 | 重构后 |
|---|---:|---:|
| JavaScript | 485742 字节 | 203855 字节 |
| JavaScript gzip | 150133 字节 | 64306 字节 |
| CSS | 60785 字节 | 13504 字节 |
| CSS gzip | 11063 字节 | 3756 字节 |

原始 JavaScript 体积减少约 58%，CSS 减少约 78%。图引擎和布局代码由工作台按需加载，其资源仍然存在；上述结果证明首屏下载减少，不能换算为页面打开耗时或生成速度提升。

原始文件见 [ui-build-before.json](../benchmarks/ui-build-before.json) 和 [ui-build-after.json](../benchmarks/ui-build-after.json)。复测时在前端目录先构建，再执行以下命令，默认检查不会改写证据。

```bash
npm run check:bundle
```

需要更新本轮结果文件时使用 `npm run check:bundle -- --write`。其他实验应保存到新文件，保留原始对照。

## 更新范围已经验证

测试通过实际工作台和详情编辑器的接口触发输入与拖动，检查对应渲染和请求是否发生。它们能检出状态重新回到父层、详情订阅重新包含位置等退化。

| 实验 | 实际观察 |
|---|---|
| 在备团正文、实际游玩记录、确认事实中各输入 20 次 | 图组件新增渲染 0 次，目录请求 0 次 |
| 选中节点后保留草稿，连续更新位置 50 次 | 详情编辑器新增渲染 0 次，草稿保留 |
| 重复写入相同节点尺寸，删除不存在节点 | 保留节点数组引用，订阅通知 0 次 |
| 测量节点尺寸 | 尺寸保存，结构身份保持原值 |

证据位于 `frontend/tests/workbenchPerformance.test.tsx` 和 `frontend/tests/workspace.test.tsx`。渲染计数使用 React Profiler 和隔离的图适配器，环境为 jsdom；它没有测量浏览器帧率。原有 5000 节点批量更新基准继续保留在[整体工程验收](refactor-validation.md)。

## 本机检查通过

完整前端测试为 110 项通过；TypeScript 与生产构建通过；Prettier 格式、模块方向、运行时循环和入口体积预算检查通过。代码格式工具固定为 Prettier 3.10.1，Pages 构建版本与 CI 统一为 Node.js 24。测试数量变化包含删除旧启动动画的两个测试、整理主题检查及新增渲染和测量检查。

在临时副本中分别引入反向依赖、运行时循环、首屏图导入和超过预算的入口文件，检查器均返回失败，原仓库未加入这些变更。结果见 [ui-guard-probes.json](../benchmarks/ui-guard-probes.json)，完整测试与构建输出见 [ui-tests.log](../benchmarks/ui-tests.log) 和 [ui-build.log](../benchmarks/ui-build.log)。

浏览器使用独立的临时数据目录。新界面跑通离线生成、编辑保存、实际场次与确认事实保存、续团、当前版本评测和重新打开剧本。续团形成版本 3，刷新后仍保留版本 2 中采用的标题与提要；记忆页显示第一场实际记录。问答在无语料时返回未检索到内容，未显示无依据的答案。

在默认桌面、900×900 和 390×844 视口检查了布局。手机首页、工作台、问答、资料库和记忆页面可访问；平板工作台及手机记忆和资料库的页面宽度未溢出。深色主题切换后刷新仍保留。这里是浏览器视口检查，尚无真实手机和软键盘验收。

截图保存在同一仓库的基准目录，分别展示[桌面首页](../benchmarks/ui-home-desktop.jpg)、[工作台](../benchmarks/ui-workbench-desktop.jpg)、[手机首页](../benchmarks/ui-home-mobile.jpg)与[手机工作台](../benchmarks/ui-workbench-mobile.jpg)。

本轮没有修改后端实现，沿用上一轮后端 506 项通过、1 项跳过的结果。真实模型内容质量、大图浏览器帧率、布局耗时和内存峰值仍未测量。模块规范的适用范围与检查限制见[维护约定](frontend-architecture.md)。
