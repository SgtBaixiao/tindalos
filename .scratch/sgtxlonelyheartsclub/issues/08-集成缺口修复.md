**交付物**：

## Answer

三个交付物全部完成并验证通过。

**1. 传输层修复（纯前端，serve.py 契约零改动）**
- `frontend/src/lib/live.ts` 新增 `fetchGenerateStream(moduleText, {llm, signal})`：`fetch(GENERATE_SSE_URL, {method:'POST', body:{module_text,llm}})` → `res.body.getReader()` + `TextDecoder({stream:true})`（跨 chunk UTF-8 续接）→ 已有 `SseStreamParser`（半帧续接/一冲多帧）逐帧 yield `SseFrame`。非 2xx 抛服务端 error 文本（或 `HTTP <status>`）；无 body 抛契约错误；`AbortController.signal` 支持取消。
- 新增 `DEMO_MODULE_TEXT = '雾港之夜'`：live 模式无工作台输入时的演示兜底，走确定性生成（`llm:false`），离线/无密钥也能实时看到 SSE 进度流。
- `frontend/src/components/ProgressBand.tsx`：EventSource effect 删除，改为 `for await` 消费 `fetchGenerateStream`；新增 `moduleText` prop；连接失败/HTTP 非 2xx/`error` 帧/流结束无 `done` 帧 → 回退静态 `progress.jsonl`（与旧回退语义一致）；unmount 时 `alive=false` + `abort()` 清理。
- `frontend/vite.config.ts`：dev proxy `'/api' → http://127.0.0.1:8347`，使 vite dev（5173）与 serve.py 同源访问（生产由反向代理承担同职）；仅 dev 生效，不影响 build/vitest。

**2. 回归测试**
- `frontend/tests/live.test.ts`：删除 `FakeEventSource`，改用 fake `fetch` + `ReadableStream`（`routeFetch` 按 URL 路由 /api/generate ↔ progress.jsonl；`sseOpenStream` 可控开放流模拟真实 serve 逐帧 push + 收尾 done+close）。② 覆盖：live POST body、无 moduleText 用 DEMO_MODULE_TEXT、done→campaignId 且不回退、连接失败/HTTP 非 2xx/error 帧→静态回退、非 live 不 POST 直接静态。
- 新增 ⑤ `fetchGenerateStream` transport 单测：POST body（含 llm 透传）、一冲多帧、半帧跨 chunk 缓冲续接、done 帧产出 campaign、HTTP 400 抛服务端消息、无 body 抛契约错误。SSE 帧严格按契约 `data:{json}\n\n` 构造。
- 结果：**frontend 82 tests 全绿**，`npx tsc --noEmit` 无错误；**test_serve.py 23 passed**（serve 契约回归）。`test_web_build.py` 唯一失败是 `test_web_dockerfile_build`——本机 Docker Desktop 未启动（daemon 不可达），与本次改动无关（未碰 Dockerfile）。

**3. 本地 serve 实测（真实 TCP 端点，与前端 fetch 同路径）**
`python -m tindalos.cli serve --port 8347` 起服务，`curl -X POST /api/generate -d '{"module_text":"雾港之夜","llm":false}'`：
- SSE 帧逐条推进：`data:{"stage":"plan","message":"KP 拟定幕结构"}` → KG 查询 → `npc`（顾长歌/苏晚晴/赵远山 注入人格）→ `write`（写作第 1/2 幕）→ `compose`（校对付印）；
- 结束帧 `data:{"done": true, "campaign": {"id":"campaign-53959297", …}}`，campaign 完整（acts/scenes/events）。
- 帧格式 `data:{json}\n\n` 与前端 `SseStreamParser` 解析契约精确吻合。验证后已停服。
