# 剧情设计参考（Scenario Design Reference）

> 来源：官方模组《留地不留头》（To Hell or Connaught，Eckhard Huelshoff 著，中文译本）全文结构解构。
> 用途：Tindalos 生成剧本的**叙事骨架、场景类型、线索链、NPC 与检定设计**参考。
> 原文提取：`references/sources/module-hell-or-connaught.txt`。

## 1. 叙事骨架（六段式）

《留地不留头》的实际结构：

| 阶段 | 模组实例 | 功能 |
|---|---|---|
| ① 背景铺垫 | 1649 爱尔兰内战史、克伦威尔登陆、圣帕特里克传说 | 建立时代可信度与神话伏笔 |
| ② 任务简报 | 克伦威尔召见：调查士兵离奇死亡 | 给玩家明确目标 |
| ③ 调查探索 | 仓库 → 地下神庙 → 医院（三处场景推进） | 逐步收集线索、埋设异常 |
| ④ 情报揭示 | 修道院图书馆：忏悔录、预言书 | 汇总结论、揭示真相全貌 |
| ⑤ 转折危机 | 内奸身份揭示、弥撒中蛇群爆发、归途伏击 | 认知颠覆 + 直接威胁 |
| ⑥ 高潮对峙 | 返回德罗赫达，博因河畔阻止召唤仪式 | 终局目标冲刺 |
| ⑦ 尾声余波 | 结局清算 | 收束主题 |

> 要点：**目标始终明确**（简报给目标），**每阶段有新信息**（信息递进），**转折改变玩家对前文的解读**（内奸视角重看全程）。

## 2. 场景类型清单（映射 Tindalos Scene）

| 类型 | 功能 | 模组实例 | 典型事件流 |
|---|---|---|---|
| 简报/会见 | 下达任务、给目标 | 克伦威尔办公室 | entry 环境 → trigger 指令 → outcome 目标确认 |
| 勘察/调查 | 收集线索、发现异常 | 仓库勘察 | entry 环境白描 → trigger 检定发现 → outcome 线索/遗漏 |
| 恐怖/异象 | 直接冲击理智 | 弥撒蛇群、停尸间 | entry 反常征兆 → trigger 恐怖爆发 → outcome san 损失 |
| 遭遇/伏击 | 行动冲突 | 归途蛇人伏击 | entry 平静 → trigger 突袭 → outcome 战斗/逃脱 |
| 情报/对话 | 汇总结论、NPC 揭示 | 修道院图书馆 | entry 氛围 → trigger 关键问答 → outcome 真相层级推进 |
| 对峙/高潮 | 终局冲突 | 博因河畔仪式 | entry 逼近 → trigger 阻止/仪式 → outcome 成败 |

## 3. 线索链设计（Clue Chain）

模组中的线索设计与呼应（可直接迁移为 Clue 节点）：

- **数量矛盾**：男孩看到「五个人死亡」，尸体却只有四具 → 引导发现隐藏第五具/伪装。
- **隐藏物证**：祭坛藏在板条箱之间、盖着帆布；灰尘痕迹暴露挪动路径 → 场景勘察的渐进发现。
- **碎片拼合**：祭坛缺失一角，找到的碎片拼出「旧印」符号 → 后续与蛇人护身符呼应。
- **跨场景呼应**：地下神庙壁画符号 ≈ 蛇人护身符图案 → 不同场景的线索互证。
- **文献揭示**：《圣帕特里克的忏悔录》（真实存在）与《埃蒙·奥哈拉的预言》→ 情报阶段汇总。
- **反常自然现象**：「爱尔兰没有蛇」→ 蛇咬尸体、沿途群蛇、弥撒涌蛇 → 同一母题的层层升级。

> 设计原则：**每条线索至少呼应一次**；调查阶段埋的细节在转折/高潮阶段回收。

## 4. NPC 设计（映射 Tindalos NPC 字段）

| 技巧 | 模组实例 |
|---|---|
| 双层身份 | 邓巴上尉（表面忠军，实为爱尔兰内奸） |
| 伪装/变形 | 缪楚吞噬布莱恩·卡文迪什并以军官身份活动 |
| 动机约束 | 缪楚「不惜一切代价避免战斗」，怕危及重获的自由——行为模式由此推导 |
| 细节质感 | 亨利·巴斯托：39 岁、赫尔港出身、约克郡口音、卡文迪什手下 |
| 功能分工 | 向导（巴斯托）、线索源（奥达菲仓库管理员）、情报源（神父们）、威胁（缪楚/蛇人部族） |
| 技能/弱点表 | 缪楚：技能 20 余项 + 法术清单 + 「避免战斗」行为注记（对应 personality/description） |

> 设计原则：**每个 NPC 有动机、有信息功能、有可辨识的细节**；重要反派给行为约束（怎么打/怎么逃/何时现身）。

## 5. 检定与后果设计（映射 Event.conditions）

模组检定格式：「成功的侦查（Spot Hidden）检定可以发现石墙发黑……一个灵感（Idea）检定可以得出结论」

- **技能 + 目标 + 成功效果**：`一个成功的 {技能} 检定可以 {发现/得知/确定} {具体信息}`。
- **多级推进**：同一地点多次检定逐步揭示（灰尘痕迹 → 祭坛位置 → 符号含义）。
- **时间成本**：部分发现需持续搜索（「持续 30 分钟的搜索」）——增加节奏感。
- **理智损失格式**：`san 0/1`（成功无损失/失败损失 1）、`san 1/1d8`（成功损失 1/失败 1d8）、`san 0/1d3`。
- **失败不卡死**：错过线索由其他路径补救（模组中多处线索可多途径获得）。

### 常见检定技能（供 conditions 引用）

侦查（Spot Hidden）· 灵感（Idea）· 知识（Know）· 历史（History）· 心理学（Psychology）· 说服（Persuade）· 医学（Medical）· 生物学（Biology）· 图书馆利用（Library Use）· 克苏鲁神话（Cthulhu Mythos）· 宗教（Religion）· 潜行（Sneak）· 聆听（Listen）

## 6. 氛围连续性设计

- **天气母题**：暴雨 + 雷暴 + 洪水贯穿全模组，开场即设定（「整个模组中都伴随着暴雨和雷暴」）。
- **物象母题**：「蛇」从无蛇之地的常识 → 蛇咬伤 → 壁画群蛇 → 护身符 → 弥撒群蛇 → 蛇人本体，逐级强化。
- **环境与剧情互文**：水位上涨（天气）↔ 地下隧道漫水（场景）↔ 洪水城镇史（背景）。

> 对 Tindalos 的要求：为整本剧本选定 1–2 个**贯穿母题**，在每幕场景中至少出现一次变奏。

## 7. 时间表结构（任务把控利器 · 燃烧的星辰）

> 来源：《燃烧的星辰》（David Conyers 著，1930 年海地背景）——按日期编排的「KP 时间表」，
> 是模组中最强的任务把控工具，可直接迁移为 Tindalos 的幕/场景规划。

模组实例（10 月 23–29 日，亡灵节前一周）：

| 日期 | 事件 | 功能 |
|---|---|---|
| 周四 | 抵达太子港开始调查；接触走私商人 | 开场 + 首个 NPC 接触 |
| 周五 | 遇到人类学家（研究《非洲的暗黑教派》） | 线索源 + 文献伏笔 |
| 周六 | 塔罗占卜师接触；搜寻星池无果 | 多线推进 + 挫败感 |
| 周日 | 学者找到星池却被吓逃；伏都祭司要求「死蛾子」换帮助 | 关键线索 + 条件交换 |
| 周一 | 抵达星池遇转化中的宿主；池中怪物灭队 | 转折 + 灾难 |
| 周二 | 幸存者疯了，被送军方医院 | 危机后遗症 |
| 周三 | 诊断为失忆症；媒体介入 | 余波 + 外部反应 |

> 设计原则：**每个时间单元（幕）推进至少一个事件 + 一个新 NPC + 一条线索/危机**；
> 灾难性事件后必须留「后遗症阶段」供角色消化与重新集结。

## 8. 精神崩溃的具体化（疯狂症状设计 · 燃烧的星辰）

> 理智崩解不能笼统写「他疯了」，要写成**可演绎的具体机制**。模组范本：

- **症状 = 防御机制**：幸存者把死去同伴变成自己的其他人格（多重人格），潜意识不让记忆浮现（失忆）——症状是心灵对真相的逃避，逻辑自洽。
- **症状有可观察表现**：自言自语（与人格对话）、看到已死朋友、行为怪异——外部视角有明确现象，并有检定触发（心理学判定注意到旁人困惑）。
- **症状影响调查**：其他人格「会去进行自己的调查线」——疯狂改变行动方式而非仅仅减分。

> 对 Tindalos 的要求：事件 outcome 涉及理智损失时，给出**具体的症状表现与行为后果**（幻觉、遗忘、执念、人格碎片），让 san 损失落地为可扮演的剧情。
