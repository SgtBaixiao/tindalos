# 生成任务与工作台操作重构

本计划供本轮实现者和评审者使用。目标是在现有功能上集中生成装配与页面操作规则，让维护者修改续团或工作台流程时少跨文件查找。

用户在 2026-11-27 要求使用 Herdr 和 Matt Pocock Skills 重构开发 `SgtBaixiao/tindalos`。本轮采用独立架构审查提出的两个模块方案；这是执行者在授权范围内作出的工程选择。基线为 `11e2362c969215b7e2fda05269b931d442836446`，分支为 `refactor/herdr-workbench-runtime`。

## 实施范围

| 任务 | 改动 | 调用方获得的简化 |
|---|---|---|
| R1 | 在 `generation_jobs.py` 集中提交准备、执行上下文和续团追加；原 `workspace.py` 入口以兼容别名保留 | HTTP 层只提交原始身份，运行器只调用执行入口 |
| R2 | 在 `site/useWorkbenchController.ts` 集中工作台操作，页面只组合展示组件 | 页面不再掌握重试键、活动任务存储、打开采用和终态刷新 |

R1 和 R2 没有功能依赖。共享 checkout 只交给一名实现者，按任务顺序修改。HTTP API、数据库 schema、命令、原数据、文案和布局保持现有语义。模块与首屏体积预算沿用现有约定。

## R1 的验收项

- AC01：先查幂等任务，再准备来源与快照；原始身份和执行输入分别传给运行器。同键重试在来源丢失或修订变化后仍返回原任务。
- AC02：提交时固定采用修订和快照，执行规则沿原优先级：有模组时使用模组规则，无模组时使用战役规则；续团结果保留采用快照的战役规则。模组全文与图像、旧文本回退、实际记录读取时点和两处上下文预算保持现状。
- AC03：生成执行仍传递图像、规则、采用 NPC 和 `persist_memory=False`，兼容短参数生成器；`None` 不合并，续团保留原幕与 NPC，不修改原快照。
- AC04：提交期 429、409、404、400 和 Pydantic 422 保持原捕获顺序；存储故障仍是服务器错误，执行期异常仍进入失败任务事件。
- AC05：运行器继续拥有容量、取消、预算、重启中断、CAS 和修订与终态事件的共同事务；新模块不自行发表结果。
- AC06：`workspace.prepare_generation`、`workspace.append_continuation`、`workspace.remap_source_ref` 继续可用；实际生成时读取 `web.default_generate`，保留现有测试替换能力。新模块不反向依赖 `workspace`。

## R2 的验收项

- AC07：挂载和恢复只读取任务，不自动 POST。相同失败输入复用重试键，修改输入换键；成功提交保存活动任务 ID，失败保留 pending，终态才清 pending。
- AC08：续团使用当前采用战役和修订。打开采用完整响应，失败保留旧剧本，结束后解除 opening；禁用条件仍为 `busy || opening`。
- AC09：取消请求返回后仍等待任务终态。终态解除 busy 并刷新目录，保留进度组件及终态显示；原错误展示优先级保持。
- AC10：复用目录的部分成功、刷新代次和卸载失效逻辑。终态回调身份稳定，图使用窄 selector，表单输入不刷新目录或重新渲染图。
- AC11：保留现有 DOM、文案、组件 key、样式、图和表单职责。Hook 位于 `site`，不放宽目录依赖规则。

## 验证与评审

测试继续通过现有 HTTP、运行器和页面交互 Interface 观察行为。新增检查先在原实现运行，再以相同断言验证重构，避免给纯提取制造人工失败或只测试私有 helper。

后端运行完整 pytest，并复测真实离线的导入、生成、编辑、重载、实际记录、续团与评测流程。前端运行完整 Vitest、格式、模块、类型、生产构建和体积检查，并在实际浏览器检查工作台流程及窄屏布局。模拟生成器和图 mock 的结果与真实离线流程分别记录。

完成实现后冻结相对于基线的完整差异，包括新增文件。按 Matt `code-review` 的两条轴分别独立审查仓库规范和本计划验收项；修复发现后复验最终差异。结果记录到本轮验收文档。

## Herdr 与交付

本机 Herdr App 为 0.1.18，Core 为 0.1.22。已安装的七个 Herdr Skill 使用旧 `herdr` 命令，而当前官方手册明确区分 `hc` 和 `herdr-app`。本轮按当前官方接口启动可交互 Agent、读取状态、等待完成和回收本任务终端，不使用旧的 pane 命令。

独立 checkout 从本地仓库克隆，避免原仓库的写作规则改动和历史数据受到影响。该规则改动原样复制到本轮 checkout。已下载 Python 3.12.16 与 uv 0.13.9，依赖按锁文件安装；环境可运行与测试通过分别核对。

本轮交付源码、测试、决策和验收记录。GitHub 上传、合并与部署分别报告实际状态。真实模型质量、KP 使用验收、大图帧率和生产容量没有现成证据，本轮不以模块提取的结果推断这些效果。
